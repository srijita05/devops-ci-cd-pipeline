# 🚀 DevOps CI/CD Pipeline Project

## 📌 Overview

This project demonstrates an end-to-end DevOps pipeline using Jenkins, Docker, and AWS.

---

## 🛠️ Tech Stack

* AWS EC2
* Docker
* Jenkins
* GitHub

---

## ⚙️ Workflow

1. Code pushed to GitHub
2. Jenkins builds the project
3. Docker image is created
4. Application deployed on AWS EC2

---

## 🐳 Docker Commands

```bash
docker build -t devops-app .
docker run -d -p 3000:3000 devops-app
```

---

## 💡 Key Learnings

* CI/CD automation
* Containerization using Docker
* Cloud deployment using AWS
